## 2. E14 — the base paper's task under its exact conditions

### 2.1 Rows and prices

- Calendar dates 2005-01-01 → 2022-03-31 (6299 dates). Labelled rows: 2005-01-01 → 2022-03-30 (6298 rows, the
  paper's count; the last date only provides the next close). Log both counts.
- Prices (OHLCV, `auto_adjust=False`): `^GSPC`, `^FTSE`, `000001.SS` from Yahoo Finance starting 2003-01-01
  (history before 2005 is used only for look-back windows and long features, never as labelled rows).
- Nifty 50: `^NSEI` on Yahoo starts 2007-09-17. Take the official NIFTY 50 price index history (OHLC) from
  NSE Indices (niftyindices.com → Historical Data → NIFTY 50) for 2003-01-01 → 2008-03-31; use it before
  2007-09-17 and Yahoo from 2007-09-17. Splice check: closes on the first 20 common days must agree within
  0.1 %; log the maximum difference. If the site cannot be reached, stop and ask Roham to place the CSV in
  `data/raw/nifty50_2003_2008.csv`. Nifty volume is masked for all dates.
- Non-trading calendar dates take all values (O, H, L, C, V) of the previous trading day, as in the paper.
- Row flags: `trading_row` (the date is a session of that market) and `informative_row` (the **next** calendar
  date is a session, so the label is set by a real price move and not by the filling). Save both.

### 2.2 News and the three sentiment indices

- Read the multisource corpus from 2005-01-01 (SPEC §2.3 started at 2007-01-01). Report local and global headline
  counts per market and year, 2005–2022. Days without local news get index 0 (SPEC §9.1).
- `S_PAPER` (for the paper-recipe SenT-In): classifier `A_PAPER` = embedding from the frozen CBOW Word2Vec
  (SPEC §3.1) → GRU(hidden 128, full sequence) → Conv1d along time (kernel 3, 64 filters; the kernel spans all
  GRU units, as §4.5 describes) + ReLU → MaxPool1d(2) → flatten → dropout 0.1 → Linear → softmax (neg/neu/pos).
  Training: cross-entropy, 400 epochs, Adam lr 0.01 (Table 2; the optimiser is not stated), batch 64, no early
  stopping, training data SPEC §2.4, seeds 0–2. Report its accuracy and macro-F1 on the SPEC §2.4 test splits.
  Score the market-tagged headlines of 2005-01-01 → 2022-03-31 (seed-averaged probabilities; seed 0 alone if
  scoring would exceed 3 h, recorded). Per headline s = p_pos − p_neg; daily index = mean s of the market's local
  headlines of the row's date.
- `S_E13`: the existing Branch A index (E13's SENTIN), extended to 2005 with the same frozen model.
- `S_SF`: SentiFlow's calibrated daily S_loc (SPEC §3.9; E13's SENTIN_SF), extended to 2005 with the frozen
  ensemble.
- Date assignment: UTC calendar date for the PUB protocols (as E13); session assignment (SPEC §2.3) for CAUSAL.

### 2.3 Labels

- `GE` (primary): y_t = 1[C_{t+1} ≥ C_t]. `GT` (secondary, E13's label): y_t = 1[C_{t+1} > C_t].
- Positive class = 1 for F1 and PR-AUC.

### 2.4 Protocols

- `PUB_C` (paper, chronological reading): calendar rows; q01/q99 min-max scaling fitted on all rows (as E13; the
  paper does not separate); train = labelled rows 2005-01-01 → 2018-10-17 (5038 rows), test =
  2018-10-18 → 2022-03-30 (1260 rows).
- `PUB_R` (paper, random reading): same rows and scaling; one random permutation of the 6298 dates (seed 2026),
  shared by the four indices: first 5038 dates train, last 1260 test.
- `CAUSAL` (this thesis): trading days only; session-aligned news; scaling fitted on the training rows; first 80 %
  of each market's trading-day samples for training, last 20 % for test; label GT (it equals GE except on exact
  zero-change sessions; record their count).
- Validation slices exist only for models whose own recipe uses one (§2.5): the last 10 % of the training rows
  (PUB_C, CAUSAL) or a random 10 % of them (PUB_R, seed 2026). Never test rows.
- Diagnostic variant `LA` (look-ahead), for PUB_C and PUB_R with label GE: the input window for label
  1[C_{t+1} ≥ C_t] ends at row t+1, whose close is replaced by C_t (the target day's open, high, low, volume
  and sentiment are visible, its close is not). It tests whether same-day information reproduces the paper's
  accuracies (0.82–0.96). Diagnostic only: never used for a claim.

### 2.5 Models

look-back 96 rows (SVM: the last 10 rows flattened), as in E13.

### 2.6 Metrics

Per setting, index and model: accuracy, F1, AUC-ROC, PR-AUC (average precision), seed mean and sd; the same four
on the `informative_row` subset of the test rows; n_train, n_test, test_start, test_end, pos_share,
informative_share. Mean over the four indices. Label evidence (diagnostic, no training): per index and label,
pos_share and the accuracy, F1 and PR-AUC of the always-positive rule on the PUB_C and PUB_R test rows.

### 2.7 Pre-registered tests and claim rules

- **Primary family (4 tests, Holm, α = 0.05, one-sided H1: ours > base):** statistic = mean over the four indices
  of AUC-ROC(ours) − AUC-ROC(`SENTIN_PAPER`), on seed-averaged scores of all test rows. Comparisons:
  `MM_CLS` vs `SENTIN_PAPER` and `SENTIN_SF_PAPER` vs `SENTIN_PAPER`, in `PUB_C_GE` and `PUB_R_GE`.
  p-value: paired stationary block bootstrap stratified by index (test rows sorted by date, mean block 10 rows,
  10 000 resamples, seed 2026); report the estimate, the two-sided 95 % interval, p and Holm p.
  Also report per-index DeLong p-values (two-sided) with Holm over the four indices.
- **Secondary metrics (same comparisons and settings, Holm within each metric):** accuracy (exact McNemar on
  threshold-0.5 predictions, pooled over indices, and the bootstrap), F1 and PR-AUC (bootstrap).
- **Validity checks (pre-registered; they decide the wording in the thesis):**
  - V1 informative rows: the primary statistic recomputed on `informative_row` test rows only.
  - V2 stronger base: `MM_CLS` vs `SENTIN_E13` and `SENTIN_SF_E13` vs `SENTIN_E13` in the same settings.
  - V3 label GT: the primary comparisons in `PUB_C_GT` and `PUB_R_GT`.
  - V4 CAUSAL: the primary comparisons in `CAUSAL` (against `SENTIN_PAPER` and `SENTIN_E13`).
- **Claim rules (write them into the report exactly):**
  - "significantly better than SenT-In under the paper's conditions" only if the primary Holm test passes in
    both `PUB_C_GE` and `PUB_R_GE`; if it passes in one, name that reading.
  - add "not explained by the filled calendar rows" only if V1 gives one-sided p < 0.05 in the same setting;
    otherwise state that the advantage comes from rows whose label is fixed by the filling.
  - add "also against the stronger reproduction of SenT-In" only if V2 gives one-sided p < 0.05.
  - V3 and V4 are reported as they come out.
- Diagnostics (LA, ROBUST, label evidence) are descriptive and never support a claim.

## 3. E15 — trading in the base paper's test window

### 3.1 Window and split

- The paper's 80:20 split of its 6298 calendar rows puts the first test row at 2018-10-18. E15 test window:
  2018-10-18 → 2022-03-31 (each market's trading days).
- Train 2010-01-01 → 2017-10-17; validation 2017-10-18 → 2018-10-17; one test run on 2018-10-18 → 2022-03-31.
  No refits inside the test window (the paper's single split).
- Note for the report: the frozen configuration was selected on development validation data ending 2018-06
  (SPEC §1), before this window starts.

### 3.2 Methods and settings

- SMART-RL with `configs/frozen.yaml` unchanged; five PPO seeds as in P5. MarketMind features: the existing annual
  refits for training-window dates; for the test window one MarketMind fit on data before 2018-10-18 (no refits),
  the same for `MM_NOSENT` where a method needs it.
- BASE: SENTIN (E13 recipe) fitted once on trading days before 2018-10-18 (its last year for early stopping);
  e = 1[P(up) > 0.5]. `BASE_PAPER`: the same with `SENTIN_PAPER` (Table 3 recipe, `S_PAPER`).
- B1–B8 as in SPEC §9 with the same single split (B6 five seeds, B7 three seeds).
- Costs 10 bps (primary) and 20 bps (sensitivity); execution and band as SPEC §5.

### 3.3 Metrics and tests

- Per market and COMBINED (SPEC §11): cum_return, ann_return, ann_vol, sharpe, sortino, mdd, calmar, turnover,
  win_rate, for the full window and the sub-window 2020-01-01 → 2022-03-31.
- Direction metrics of the SMART-RL, BASE and BASE_PAPER decisions on the test window (prediction 1[e_t > 0.5],
  score e_t, label 1[C_{t+1} > C_t] on trading days): accuracy, F1, AUC-ROC, PR-AUC.
- SMART-RL versus BASE, BASE_PAPER and B1_BH on COMBINED: Ledoit–Wolf HAC and bootstrap p-values for the Sharpe
  difference (one-sided, SPEC §12), stationary-bootstrap 95 % intervals for the MDD and cumulative-return
  differences. Descriptive; no new hypothesis.
- Overlap without retraining: from the existing P5 daily returns, the same trading metrics on
  2020-01-01 → 2022-03-31 (`e15.p5overlap`).
